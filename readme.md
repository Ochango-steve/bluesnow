# MikroTik Bypass Toolkit

A stealth GUI utility to simulate bypass techniques on MikroTik captive portals for labs and red team simulations.  
Supports both Windows and Kali Linux.

## Features
- MAC spoof (Linux)
- DNS tunneling (iodine)
- Evil Twin phishing launcher
- M-PESA and MikroTik-style login clones
- Credential looter to `/tmp/loot.txt` or `C:/Users/Public/loot.txt`
